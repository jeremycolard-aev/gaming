# Media

Ce dossier contient les ressources non structurées du jeu (audio, images, etc.).

## Structure prévue

```
media/
├── audio/         # Sons et musiques du jeu
│   ├── sfx/       # Effets sonores
│   └── music/     # Musiques de fond
├── images/        # Images et sprites
│   ├── sprites/   # Sprites de personnages
│   └── tiles/     # Tuiles de niveaux
└── README.md      # Ce fichier
```

## Utilisation

Les fichiers ajoutés ici peuvent être référencés dans le code via le dossier `public/` après intégration.
